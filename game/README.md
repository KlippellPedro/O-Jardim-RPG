# Jogo 2D de O Jardim — pré-produção pausada

Esta pasta reserva o contexto para um possível jogo 2D de **O Jardim RPG**.
O projeto ainda **não foi iniciado**: não há código, assets de produção, escopo
aprovado nem compromisso de cronograma.

O planejamento registrado em 30 de agosto de 2026 está em
[docs/PLANEJAMENTO_INICIAL.md](docs/PLANEJAMENTO_INICIAL.md).

Ao retomar:

1. reler o planejamento e confirmar as decisões pendentes;
2. reler [`../docs/EDITOR_CONTEUDO_CAMPANHA.md`](../docs/EDITOR_CONTEUDO_CAMPANHA.md)
   antes de integrar lore, cronologia, regras ou conteúdo publicado;
3. conferir novamente os dados e as versões atuais das ferramentas;
4. começar por uma prova de movimento e combate, não pelo jogo completo.

Não colocar nesta pasta exportações finais, segredos, tokens, snapshots privados
ou material sem licença de uso confirmada.
